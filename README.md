# 🎱 Більярд Онлайн

Вісімка (8-ball) у браузері: онлайн з другом за кодом кімнати, проти бота або вдвох за одним компом.

**Грати:** https://camio1447-netizen.github.io/billiard/

## Як пограти з другом

1. Відкрий гру за посиланням вище.
2. Тисни **«Створити гру онлайн»** — отримаєш код типу `K7PWM`.
3. Друг відкриває те саме посилання → **«Приєднатися за кодом»** → вводить код.
   Або просто кинь йому «Скопіювати посилання» — код уже вшитий.

З'єднання пряме (P2P через PeerJS), сервер для гри не потрібен.

## Фішки

- Чесна фізика: двофазне тертя, підкрутка (накат/відтяжка/бокова), «throw» на різаних, кочення куль.
- Приціл з траєкторією, підсвіткою лузи та поправкою на throw.
- Бот Вася 🤖, реванші, рахунок серії, емодзі-реакції, звуки.
- Керування: клік/драг — приціл, слінгшот від білої, повзунок сили, ←/→ — точність.

## Локально

```
node server.js
```
і відкрий http://localhost:3199. Або просто відкрий `index.html` подвійним кліком.

`ГРАТИ-ОНЛАЙН.cmd` — підняти тунель (Cloudflare / localhost.run), якщо хочеться пограти з локальної версії без сайту.

## Оновлення сайту

`ОНОВИТИ-САЙТ.cmd` — підніме версію, закомітить і запушить: сайт оновиться сам за ~1 хв, а відкриті вкладки гравців покажуть «Вийшла нова версія».
